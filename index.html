关于碎碎念

一个用拼图传递心意的情感品牌

「碎碎念」—— 那些藏在心里、反复念叨却说不出口的话，化作一片片拼图。当对方一片片拼起，完整的心意才终于被看见。

品牌故事

我们都有过这样的时刻：想对某个人说些什么，却不知如何开口。写一封信太重，发一条消息太轻。于是我们创造出「碎碎念」—— 一张看似普通的拼图明信片，背面写满了你想说的话。但只有当你把 60 片碎片一块块拼完整，那些藏在背面的文字才会显现。

拼图的过程，就是打开心意的仪式。每一片碎片都是一句未完的念想，拼完整了，心意才能被读懂。

品牌名释义

碎

碎片、破碎。60 片拼图，每一片都承载着不完整的心意。碎的形态，恰恰是心意的容器。

念

念想、思念、念叨。那些萦绕心头的话语，反复斟酌却从未说出口。念是情感本身。

品牌定位

在礼品市场中的独特坐标

核心定位

碎碎念 = 有仪式感的心意表达载体
不是一张卡片，不是一段文字，而是一次需要亲手完成的"阅读仪式"。

目标人群

💕

情感表达者

18-35 岁情侣、准情侣，追求走心而有仪式感的告白/纪念日礼物。不满足于千篇一律，想要"被记住的惊喜"。

👯

深度关系守护者

闺蜜、挚友之间。毕业、生日、异地——在重要节点，用一份需要"亲手拼完"的礼物传递用心。

🎁

创意场景需求方

创意邀请函、团建破冰、景区文创、企业定制。需要互动感与记忆点的 B 端/小 B 场景。

品牌主张

主 Slogan：拼完整，才能看懂我的心意

这句话既是产品使用方式的直白描述，也是情感隐喻——心意的表达需要耐心与投入，而"看懂"是两个灵魂之间的默契。

差异化优势

维度传统贺卡/明信片普通礼品碎碎念
参与感低（翻开即读）低高（60片拼图 = 60次触碰）
惊喜感中中极高（拼完才揭晓）
仪式感低中极高（拼图 = 仪式）
情感承载中因物而异极深（手写 + 隐藏）
留存价值低中高（可装裱保存）

品牌理念

驱动品牌前行的核心信念

🌱 使命

让每一份深藏的心意，都能被郑重地打开。
用拼图的仪式感，为人们创造值得铭记的情感瞬间。

🔭 愿景

成为中国「心意表达」品类的第一联想品牌。
当人们想要一份"走心"的礼物时，第一个想到碎碎念。

品牌价值观

🤲

真诚

手写的温度无法被印刷取代。我们守护每一份真实的情感表达。

✨

仪式感

碎片是故意设置的障碍，拼图是精心设计的仪式。仪式让情感有了分量。

🎨

美的坚持

从拼图图案到包装，从文案到视觉，每一个触点都必须是美的体验。

核心精神：拼图即心意

60 片碎片，承载 60 句未说出口的话。拼图的过程不是麻烦，而是心意的重量。只有愿意花时间拼完的人，才值得读到那些话。

这个核心精神贯穿品牌的每一个触点——产品设计中拼图片数与尺寸的平衡（60片 = 15-20分钟，不长不短刚好是"用心"的时间）、包装的揭秘体验、文案中反复出现的"拼""碎""念"意象。

品牌调性

碎碎念如何说话、如何被感知

品牌人格

理性 / 商务
温暖 / 走心 / 细腻
浮夸 / 煽情

碎碎念是「温柔的朋友」—— 不喧哗、不说教，但懂得你心里那些细腻的情绪。

品牌语调关键词

温柔
不尖锐、不强势
细腻
关注微小的情绪
真诚
不说套话、不套路
惊喜
藏着期待与发现

文案调性指南

✅ DO · 这样写

  • 用第二人称"你"，像在和朋友聊天
  • 描述具体场景和情绪，而非抽象概念
  • 留白——给读者想象空间
  • 融入"拼""碎""念"的品牌意象
  • 短句为主，节奏舒缓

❌ DON'T · 避免这样

  • 过度煽情，或使用空洞的套话
  • 营销感强的促销语言
  • 说教——"你应该……"
  • 使用过于年轻/网络化的梗
  • 粗暴对比竞品

文案示例

好的示例：
"有些话在心里念叨了很久，写下来又撕掉。这次我把它藏进了 60 片碎片里。等你拼完，就能看到了。"

避免的示例：
"超感人的拼图礼物！送TA绝对感动哭！限时优惠，赶快下单吧！"

品牌识别的核心符号

标准 Logo

「碎碎念」品牌 Logo 以手写感字体为主体，传递温暖、手工、独一无二的情感特质。

Logo 安全空间

为确保 Logo 在任何应用中清晰可见，四周需保留最小安全空间。以 Logo 中"碎"字的高度为 X，安全空间为 0.5X。

Logo 最小尺寸

应用场景最小宽度说明
印刷（包装/卡片）20mm保证手写笔触清晰可辨
屏幕（电商/社交）80px在手机屏幕上清晰显示
特殊工艺（烫金/压印）15mm需根据工艺调整细节

Logo 使用禁忌

✅ 正确用法

  • 使用品牌标准色或单色版本
  • 保持与背景的足够对比度
  • 保持标准比例，等比缩放

❌ 错误用法

  • 拉伸、压缩、旋转变形
  • 添加阴影、描边等额外效果
  • 放在复杂纹理/图片上导致难以辨认
  • 更改字体或字间距
  • 使用非品牌色系配色

字体规范

文字的形态即品牌的语气

品牌标识字体

「碎碎念」品牌名使用手写风格字体，传达温暖、手作、独一无二的情感。

推荐：使用具有手工笔触感的手写体/书法体，字重适中，不宜过细（显冷淡）或过粗（显笨拙）。

辅助图形与插画

丰富品牌视觉层次的表达元素

核心辅助图形：拼图碎片

拼图碎片是碎碎念最核心的视觉符号。碎片形态可以灵活应用于各种场景，是品牌识别的重要延伸。

碎片 · 完整形态

6块左右的拼图碎片正在拼接中——呈现"正在进行"的仪式感。用于包装封面、主视觉。

碎片 · 散落形态

多片碎片随机分布——呈现"期待被拼起"的状态。用于背景纹理、包装内里。

碎片 · 单一片

单片拼图作为图标/点缀使用。用于标签、icon、社交媒体头像。

碎片 · 拼接完成

拼图完整呈现 + 手写文字浮现。用于产品完成示意、结尾页。

辅助图形规范

元素规范说明
拼图凸起圆角，不过于尖锐保持柔和感，匹配品牌调性
碎片线条0.5-1pt，深棕 #5A3A28描边不过粗，保持精致
碎片间距1-2mm（散落）/ 0（拼接）根据场景调整
排列角度散落时自然随机，不刻意避免整齐排列，保留手工感

插画风格

推荐风格：温暖手绘风 —— 线条柔和、色调温暖、有人情味的插画。避免过于几何化或冷感的矢量风格。

人物

简笔手绘，不追求写实。重在情感氛围而非细节。

场景

温暖的日常场景：写信、拆礼物、拼图、拥抱。

装饰

信封、邮票、丝带、花瓣——温柔小巧的装饰元素。

包装规范

包装是品牌体验的第一道仪式

包装设计理念

拆封 = 仪式开始。包装不仅是保护产品，更是"揭秘体验"的序章。从拆开包装的那一刻，用户就进入了碎碎念设计的情感旅程。

标准包装结构

层级形态材质建议品牌元素
外封套牛皮纸信封 / 天地盖盒牛皮纸 200g+ / 灰板裱纸Logo + Slogan + 碎片图案
封条/贴纸圆形/异形贴纸半透明硫酸纸 / 和纸Logo + 「拆开，开始拼」
内衬拼图托底 + 说明卡白卡纸品牌色 + 使用说明
碎片包装透明袋 / 硫酸纸袋OPP袋 / 硫酸纸品牌封口贴

包装色彩规范

✅ 推荐

  • 牛皮纸原色 + 品牌杏色点缀
  • 米白底 + 深棕文字 + 杏色强调
  • 暖白色系大面积留白
  • 细节处使用烫金/烫银工艺

❌ 避免

  • 大面积使用深色或黑色
  • 高饱和度荧光色
  • 过于复杂的图案堆叠
  • 反光材质/镭射效果

包装文案规范

外包装必须包含：品牌 Logo、产品名「60片秘密拼图明信片」、Slogan「拼完整，才能看懂我的心意」、拼图片数标识。

可选元素：品牌故事一句话、使用说明二维码、社交账号。

传播视觉规范

✅ DO

  • 所有传播物料使用品牌色系
  • 图片色调温暖、光线柔和
  • 露出品牌 Logo（保持安全空间）
  • 产品图片保持高质量，统一调色

❌ DON'T

  • 使用与品牌调性不符的冷色调滤镜
  • 过度修图失去真实感
  • Logo 变形或变色
  • 与其他品牌素材混用
